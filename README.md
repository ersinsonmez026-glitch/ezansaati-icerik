# Ezan Saati · içerik

Ezan Saati uygulamasının Mesaj Kartları sayfasındaki videolar. Uygulama `videolar.json` listesini okur.

- Videolar [Pixabay](https://pixabay.com/) içeriğinden (Pixabay Content License) üretilir; her kaydın `lisans` alanında kaynak sayfası vardır.
- Üzerindeki ayet mealleri ve hadisler uygulamadaki kaynaklı metinlerdir.
- Yazı tipi: Lora (SIL Open Font License, `arac/yazi/Lora-OFL.txt`).
- Yalnız onaylanan videolar `videolar/` klasörüne ve listeye girer.
